# Keywords

## iOS — App Store keyword field (100 characters max per locale)

Rules applied: comma-separated, no spaces after commas, no app name ("ZOTAIX"
is already indexed from the title), no category name repetition ("lifestyle"
is indexed from the category), singular forms only.

### en-US (100/100 chars)

```
ai gift,custom spirits,fragrance,bottle design,gifting,bespoke,concierge,label,keepsake,archive,wine
```

### zh-Hans (69/100 chars — Chinese terms are shorter; headroom kept for ASO iteration)

```
定制酒,礼物,香氛,AI礼宾,情绪,礼盒,纪念,共创,瓶身设计,企业礼赠,档案,威士忌,调香,送礼,生日礼物,情人节,周年纪念,香水,定制
```

### Term rationale

| Term | Why |
| --- | --- |
| ai gift / AI礼宾 | Highest-intent discovery phrase for the core loop |
| custom spirits / 定制酒 | Category head term for the Forge line |
| fragrance / 香氛, 调香, 香水 | Fragrance direction generation |
| bottle design / 瓶身设计 | Studio feature |
| gifting, bespoke / 礼物, 送礼, 礼盒 | Gift-occasion searches |
| concierge | Differentiator vs. catalog apps |
| label | Label copy + sticker labels (Supply) |
| keepsake, archive / 纪念, 档案 | Reserve positioning |
| wine / 威士忌 | Adjacent category searches |
| 共创 | Co-creation pool |
| 企业礼赠 | Enterprise/Maison searches |
| 生日礼物, 情人节, 周年纪念 | Occasion long-tail |

Do not spend characters on: `app`, `free`, `zotaix`, `卓序` (title-indexed),
or competitor brand names (rejection risk).

## Android — Google Play

Play has no keyword field; ranking reads the **title**, **short
description**, and **long description**.

1. **Title** stays `ZOTAIX` (brand integrity beats keyword stuffing; stuffed
   titles are policy-flagged).
2. **Short description** carries the head terms — the 80-char strings in
   `descriptions.md` already contain: bespoke spirits, fragrances, bottles,
   archived gifts / 定制酒饮、香氛、礼赠.
3. **Long description** should mention each target term 2–3 times naturally
   (the provided copy does); never paste comma lists — Play flags keyword
   stuffing.
4. **Localized listings**: publish en-US and zh-CN listings with the copy
   from `descriptions.md`; each locale is indexed separately.
5. **Custom store listings**: if regional storefronts get the zero-proof
   Supply positioning (see `app-name.md` regional notes), create a custom
   listing for those countries rather than editing the default.
